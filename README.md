# Employee Management System

This is a simple console-based employee management system written in C and C++. It allows users to manage employee, department, and work details records.

## Features

*   **Display Records**: View lists of all employees, departments, and their work details.
*   **Add Records**: Add new employees, departments, and work details.
*   **Modify Records**: Update existing records for employees, departments, and work details.
*   **Search Records**: Search for employees, departments, and work details based on various criteria.
*   **Password Protection**: The application has a simple password protection mechanism. The password is `111`.

## How to Compile and Run

This project was developed using Turbo C++ and is intended for a DOS-based environment. To compile and run this project, you will need a C++ compiler that supports the `<conio.h>` library, such as Turbo C++.

1.  **Compiler**: Use a compiler like Turbo C++. The `Turbo.C.3.2.zip` file in this repository might contain a compatible compiler.
2.  **Source File**: The main source code file is `source/Employee Management System.CPP`.
3.  **Compilation**: Compile the `Employee Management System.CPP` file using your C++ compiler.
4.  **Execution**: Run the generated executable file (`Employee Management System.EXE`).

## Project Structure

*   `source/Employee Management System.CPP`: The main C++ source code for the application.
*   `source/Employee Management System.EXE`: The compiled executable file for the application.
*   `Turbo.C.3.2.zip`: An archive that likely contains the Turbo C++ compiler.
*   `README.md`: This file.

## Note

This application stores data in memory, which means any changes (additions, modifications) will be lost when the program is closed. There is no database or file persistence.
